# Research tables

These compact extracts were built from official public sources for the Phase 4 research pages. They are not a substitute for the source workbooks, PDFs, and agency pages cited in each JSON file.

| File | Contents |
| --- | --- |
| `county-pop-history.json` / `.csv` | County and state population, 1790–2025 |
| `nc-tax-collections.json` | Census state tax collections and NCpedia governor year ranges |
| `nc-acs-benchmarks.json` | 2024 ACS 5-year foreign-born and language estimates |
| `nc-migration-irs.json` | IRS SOI state-to-state migration, filing years 2023–2024 |
| `nc-health-sourced.json` | SCHS 2018–2023 resident pregnancy statistics and the 2024 NCDHHS statutory report |

Pennsylvania research files from the upstream project were not copied here.

Rebuild with `python3 tools/build-phase4.py` from a machine that has the official source files under `/workspace/nc-home-data/phase4`.
